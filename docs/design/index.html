Why this look

Invites compete with screenshots in a group chat. A big photo + serif title reads as "a real invitation" in under a second, and the paper tone makes any user photo look warmer and more intentional.

Interaction rules

  • Every tap target ≥ 48px; RSVP buttons 64px.
  • Answers save instantly (optimistic), with a quiet "Saved" state.
  • Comments are plain text — no links, so no spam payoff.

Free to run

  • One Cloudflare Worker + one D1 database. That's the whole backend.
  • $0, no credit card, no domain needed (*.workers.dev).
  • Photos live in D1 as small WebP files, so there's no storage bucket to set up.
  • Invites delete themselves 30 days after the event, so storage stays small.

Fast in any browser

  • Just a link. No app, no install, works on any phone.
  • Pages arrive fully rendered: ~30 KB of HTML/CSS/JS before the photo.
  • Photos are shrunk in the browser before upload; the list uses 20 KB thumbnails.
  • Self-hosted font subsets and inline SVG icons. No third-party requests to wait on.
